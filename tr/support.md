# Destek

Action Translation ile ilgili yardıma mı ihtiyacınız var? Bize ulaşın veya aşağıdaki yanıtlara göz atın.

## İletişim

[action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) adresine e-posta gönderin veya [GitHub'da bir issue açın](https://github.com/claustrofob/actiontranslation/issues). Issue'lar herkese açıktır, bu nedenle kişisel bilgi veya API anahtarı eklemeyin.

## Başlarken

1. [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys) veya [OpenAI](https://platform.openai.com/settings/organization/api-keys) üzerinden bir API anahtarı alın.
2. Uygulamada **Ayarlar**'ı açın, bir sağlayıcı seçin ve anahtarınızı **API Anahtarı** alanına yapıştırın.
3. Metni girin ve **Çevir**'e dokunun. Başka bir uygulamadan çeviri yapmak için metni seçin, **Paylaş**'a ve ardından **Çevir**'e dokunun.

## Sık sorulan sorular

### Neden API anahtarına ihtiyacım var?

Action Translation'ın kendi sunucusu veya hesapları yoktur. Uygulama, anahtarınızı kullanarak metninizi seçtiğiniz yapay zekâ sağlayıcısına doğrudan gönderir. Bu kullanım için ücret varsa sağlayıcıdaki planınıza bağlıdır.

### Uygulama API anahtarının eksik olduğunu söylüyor

**Ayarlar**'ı açın, istediğiniz sağlayıcıyı seçin ve API anahtarını ekleyin. Her sağlayıcı için ayrı bir anahtar gerekir.

### Uygulama API anahtarının geçersiz olduğunu söylüyor

Anahtarın tamamını kopyaladığınızdan ve sağlayıcı hesabınızda hâlâ etkin olduğundan emin olun. Gerekirse yeni bir anahtar oluşturun.

### Uygulama istek sınırının aşıldığını söylüyor

Çok fazla istek gönderdiniz veya planınızın sınırına ulaştınız. Biraz bekleyip yeniden deneyin ya da sağlayıcıdaki planınızı kontrol edin.

### Paylaş menüsünde Çevir'i bulamıyorum

Önce metni seçin, **Paylaş**'a dokunun ve eylem listesine kaydırın. iOS aynı adla kendi eylemini de gösterebileceğinden Action Translation simgeli **Çevir**'i arayın. Favorilerinize eklemek için **Eylemleri Düzenle…**'ye dokunun.

### Bir çeviriyi nasıl silerim?

Geçmişte çeviriyi sola kaydırın ve **Sil**'e dokunun.
