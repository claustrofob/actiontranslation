# सहायता

Action Translation में मदद चाहिए? हमसे संपर्क करें या नीचे दिए गए उत्तर देखें।

## संपर्क

[action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) पर ईमेल करें या [GitHub पर issue खोलें](https://github.com/claustrofob/actiontranslation/issues)। Issues सार्वजनिक होते हैं, इसलिए उनमें व्यक्तिगत जानकारी या API कुंजियाँ न लिखें।

## शुरुआत करें

1. [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys) या [OpenAI](https://platform.openai.com/settings/organization/api-keys) से API कुंजी प्राप्त करें।
2. ऐप में **सेटिंग्ज़** खोलें, कोई प्रदाता चुनें और **API कुंजी** फ़ील्ड में अपनी कुंजी पेस्ट करें।
3. टेक्स्ट दर्ज करें और **अनुवाद करें** पर टैप करें। किसी अन्य ऐप से अनुवाद करने के लिए टेक्स्ट चुनें, **शेयर करें** पर टैप करें और फिर **अनुवाद करें** पर टैप करें।

## सामान्य प्रश्न

### मुझे API कुंजी की ज़रूरत क्यों है?

Action Translation का अपना कोई सर्वर या खाता नहीं है। ऐप आपकी कुंजी का उपयोग करके आपका टेक्स्ट सीधे आपके चुने हुए AI प्रदाता को भेजता है। इस उपयोग का कोई शुल्क होने पर वह प्रदाता के साथ आपके प्लान पर निर्भर करता है।

### ऐप बताता है कि API कुंजी मौजूद नहीं है

**सेटिंग्ज़** खोलें, अपना प्रदाता चुनें और उसकी API कुंजी जोड़ें। हर प्रदाता के लिए अलग कुंजी चाहिए।

### ऐप बताता है कि API कुंजी अमान्य है

जाँचें कि आपने पूरी कुंजी कॉपी की है और वह प्रदाता के खाते में अभी सक्रिय है। ज़रूरत होने पर नई कुंजी बनाएँ।

### ऐप बताता है कि अनुरोधों की सीमा पार हो गई है

आपने बहुत अधिक अनुरोध भेजे हैं या अपने प्लान की सीमा तक पहुँच गए हैं। थोड़ी देर रुककर फिर से कोशिश करें या प्रदाता के साथ अपना प्लान देखें।

### मुझे शेयर मेनू में अनुवाद करें नहीं मिल रहा

पहले टेक्स्ट चुनें, **शेयर करें** पर टैप करें और कार्रवाइयों की सूची तक नीचे स्क्रॉल करें। Action Translation आइकन वाला **अनुवाद करें** ढूँढें, क्योंकि iOS इसी नाम की अपनी कार्रवाई भी दिखा सकता है। इसे पसंदीदा में जोड़ने के लिए **कार्रवाइयाँ संपादित करें…** पर टैप करें।

### मैं अनुवाद कैसे हटाऊँ?

इतिहास में उसे बाईं ओर स्वाइप करें और **डिलीट करें** पर टैप करें।
