# นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 8 พฤศจิกายน พ.ศ. 2569

Action Translation เป็นแอปสำหรับ iPhone และ iPad ที่แปลข้อความโดยใช้ผู้ให้บริการ AI ที่คุณเลือก นโยบายนี้อธิบายว่าเกิดอะไรขึ้นกับข้อมูลของคุณเมื่อคุณใช้แอป

## สรุป

- ผู้พัฒนา Action Translation ไม่เก็บรวบรวม ไม่ได้รับ และไม่จัดเก็บข้อมูลของคุณ แอปไม่มีบัญชีผู้ใช้ เซิร์ฟเวอร์ โฆษณา การวิเคราะห์ หรือการติดตาม
- เมื่อคุณเริ่มแปล ข้อความจะถูกส่งจากอุปกรณ์ของคุณไปยังผู้ให้บริการ AI ที่คุณเลือกโดยตรง
- ประวัติการแปล การตั้งค่า และคีย์ API จะเก็บไว้ในอุปกรณ์ของคุณ

## ข้อมูลที่ส่งไปยังผู้ให้บริการ AI

การเพิ่มคีย์ API ในการตั้งค่าถือว่าคุณอนุญาตให้แอปส่งข้อมูลที่อธิบายไว้ด้านล่างไปยังผู้ให้บริการรายนั้น หากต้องการเพิกถอนการอนุญาต ให้ลบคีย์

จะไม่มีการส่งข้อมูลใดๆ จนกว่าคุณจะเริ่มแปล เมื่อเริ่มแปล แอปจะส่งข้อมูลต่อไปนี้ไปยังผู้ให้บริการที่เลือกไว้ในการตั้งค่า (Google, Anthropic หรือ OpenAI) โดยตรง:

- ข้อความที่คุณต้องการแปล
- คำสั่งการแปล รวมถึงโมเดล ภาษาปลายทาง ภาษาต้นทางหากคุณเลือกไว้ และภาษาของอินเทอร์เฟซแอป
- คีย์ API ของคุณ ซึ่งผู้ให้บริการใช้ระบุตัวคุณ

เช่นเดียวกับบริการอินเทอร์เน็ตทั่วไป ผู้ให้บริการจะได้รับข้อมูลการเชื่อมต่อทางเทคนิคด้วย เช่น ที่อยู่ IP ของคุณ

ผู้ให้บริการจะจัดการข้อมูลนี้ตามข้อกำหนด นโยบายความเป็นส่วนตัวของตน และข้อตกลงที่มีกับคุณ ข้อกำหนดอาจแตกต่างกันไปตามแพ็กเกจ เช่น แพ็กเกจฟรีบางแพ็กเกจอนุญาตให้ผู้ให้บริการใช้เนื้อหาที่ส่งเข้ามาเพื่อปรับปรุงผลิตภัณฑ์ โปรดตรวจสอบข้อกำหนดของผู้ให้บริการก่อนแปลข้อมูลที่เป็นความลับหรือข้อมูลส่วนบุคคล

- [นโยบายความเป็นส่วนตัวของ Google](https://policies.google.com/privacy) และ[ข้อกำหนดของ Gemini API](https://ai.google.dev/gemini-api/terms)
- [นโยบายความเป็นส่วนตัวของ Anthropic](https://www.anthropic.com/legal/privacy)
- [นโยบายความเป็นส่วนตัวของ OpenAI](https://openai.com/policies/privacy-policy/)

## ข้อมูลที่อยู่ในอุปกรณ์ของคุณ

- **ประวัติการแปล:** การแปล 50 รายการล่าสุด รวมถึงข้อความต้นฉบับ ผลลัพธ์ ภาษา โมเดล วันที่ และเวลาตอบสนอง การแปลที่เก่ากว่านั้นจะถูกลบโดยอัตโนมัติ
- **การตั้งค่า:** ผู้ให้บริการ โมเดล ภาษาปลายทาง และภาษาที่คุณใช้บ่อยที่สุด
- **คีย์ API:** จัดเก็บไว้ในพวงกุญแจ iOS

แอปและส่วนขยายการแชร์ของแอปใช้ข้อมูลนี้ร่วมกันในอุปกรณ์ของคุณ แอปไม่ซิงค์ข้อมูลนี้กับเซิร์ฟเวอร์ใดๆ แต่ข้อมูลอาจรวมอยู่ในข้อมูลสำรองของอุปกรณ์ตามการตั้งค่า iOS ของคุณ

## เนื้อหาจากแอปอื่นและการเข้าถึงอุปกรณ์

ส่วนขยายการแชร์จะได้รับเฉพาะข้อความหรือลิงก์ที่คุณเลือกแชร์เท่านั้น แอปจะเขียนลงในคลิปบอร์ดเฉพาะเมื่อคุณแตะคัดลอก แอปไม่ขอเข้าถึงรายชื่อ รูปภาพ ตำแหน่ง ไมโครโฟน หรือกล้องของคุณ

## การลบข้อมูลของคุณ

- หากต้องการลบการแปล ให้ปัดรายการนั้นในประวัติ
- หากต้องการนำคีย์ API ออก ให้ล้างช่องของคีย์นั้นในการตั้งค่า
- การลบแอปจะลบประวัติและการตั้งค่าของคุณ iOS อาจเก็บรายการในพวงกุญแจไว้หลังจากลบแอป ดังนั้นโปรดล้างคีย์ API ก่อน
- หากต้องการเข้าถึงหรือลบข้อมูลที่ผู้ให้บริการ AI เก็บไว้ โปรดติดต่อผู้ให้บริการรายนั้น

## Apple และเว็บไซต์นี้

Apple จัดการการดาวน์โหลดจาก App Store ตามนโยบายความเป็นส่วนตัวของ Apple หากคุณเลือกแชร์ข้อมูลการวิเคราะห์กับนักพัฒนาแอปในการตั้งค่า iOS Apple อาจให้รายงานข้อขัดข้องและการใช้งานที่ไม่ระบุตัวคุณแก่ผู้พัฒนา

เว็บไซต์นี้โฮสต์บน GitHub Pages และ GitHub อาจบันทึกที่อยู่ IP ของผู้เข้าชม ตัวเว็บไซต์เองไม่ใช้คุกกี้หรือเครื่องมือวิเคราะห์

## เด็ก

ผู้พัฒนาไม่เก็บรวบรวมข้อมูลส่วนบุคคลของบุคคลใดโดยเจตนา รวมถึงเด็ก

## การเปลี่ยนแปลงนโยบายนี้

หากนโยบายนี้มีการเปลี่ยนแปลง เวอร์ชันใหม่จะเผยแพร่บนหน้านี้พร้อมวันที่ใหม่
