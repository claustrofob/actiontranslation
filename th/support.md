# ฝ่ายสนับสนุน

ต้องการความช่วยเหลือเกี่ยวกับ Action Translation ใช่ไหม ติดต่อเราหรือดูคำตอบด้านล่าง

## ติดต่อ

ส่งอีเมลไปที่ [action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) หรือ[เปิด issue บน GitHub](https://github.com/claustrofob/actiontranslation/issues) Issue เป็นข้อมูลสาธารณะ จึงไม่ควรใส่ข้อมูลส่วนบุคคลหรือคีย์ API

## เริ่มต้นใช้งาน

1. รับคีย์ API จาก [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys) หรือ [OpenAI](https://platform.openai.com/settings/organization/api-keys)
2. ในแอป เปิด **การตั้งค่า** เลือกผู้ให้บริการ แล้ววางคีย์ในช่อง **คีย์ API**
3. ป้อนข้อความแล้วแตะ **แปล** หากต้องการแปลจากแอปอื่น ให้เลือกข้อความ แตะ **แชร์** แล้วแตะ **แปล**

## คำถามที่พบบ่อย

### ทำไมจึงต้องใช้คีย์ API

Action Translation ไม่มีเซิร์ฟเวอร์หรือบัญชีของตนเอง แอปจะใช้คีย์ของคุณส่งข้อความไปยังผู้ให้บริการ AI ที่คุณเลือกโดยตรง ค่าใช้จ่ายในการใช้งาน (ถ้ามี) ขึ้นอยู่กับแพ็กเกจของคุณกับผู้ให้บริการ

### แอปแจ้งว่าไม่มีคีย์ API

เปิด **การตั้งค่า** เลือกผู้ให้บริการที่ต้องการ แล้วเพิ่มคีย์ API ของผู้ให้บริการนั้น ผู้ให้บริการแต่ละรายต้องใช้คีย์ของตนเอง

### แอปแจ้งว่าคีย์ API ไม่ถูกต้อง

ตรวจสอบว่าคุณคัดลอกคีย์มาครบถ้วนและคีย์ยังใช้งานได้ในบัญชีผู้ให้บริการของคุณ หากจำเป็นให้สร้างคีย์ใหม่

### แอปแจ้งว่าเกินขีดจำกัดคำขอ

คุณส่งคำขอมากเกินไปหรือถึงขีดจำกัดของแพ็กเกจแล้ว โปรดรอสักครู่แล้วลองอีกครั้ง หรือตรวจสอบแพ็กเกจของคุณกับผู้ให้บริการ

### หา แปล ในเมนูแชร์ไม่พบ

เลือกข้อความก่อน แตะ **แชร์** แล้วเลื่อนลงไปที่รายการการทำงาน มองหา **แปล** ที่มีไอคอน Action Translation เนื่องจาก iOS อาจแสดงการทำงานของตนเองที่มีชื่อเดียวกัน หากต้องการเพิ่มในรายการโปรด ให้แตะ **แก้ไขการทำงาน…**

### จะลบการแปลได้อย่างไร

ปัดรายการไปทางซ้ายในประวัติ แล้วแตะ **ลบ**
