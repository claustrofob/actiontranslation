# Pomoc

Potrzebujesz pomocy z Action Translation? Skontaktuj się z nami lub sprawdź odpowiedzi poniżej.

## Kontakt

Napisz na adres [action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) lub [utwórz zgłoszenie w serwisie GitHub](https://github.com/claustrofob/actiontranslation/issues). Zgłoszenia są publiczne, więc nie podawaj w nich danych osobowych ani kluczy API.

## Pierwsze kroki

1. Uzyskaj klucz API od [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys) lub [OpenAI](https://platform.openai.com/settings/organization/api-keys).
2. W aplikacji otwórz **Ustawienia**, wybierz dostawcę i wklej klucz w polu **Klucz API**.
3. Wpisz tekst i stuknij **Przetłumacz**. Aby przetłumaczyć tekst z innej aplikacji, zaznacz go, stuknij **Udostępnij**, a następnie **Przetłumacz**.

## Częste pytania

### Dlaczego potrzebuję klucza API?

Action Translation nie ma własnego serwera ani kont. Aplikacja wysyła tekst bezpośrednio do wybranego dostawcy AI, korzystając z Twojego klucza. Ewentualne opłaty za to użycie zależą od Twojego planu u dostawcy.

### Aplikacja informuje o braku klucza API

Otwórz **Ustawienia**, wybierz dostawcę i dodaj jego klucz API. Każdy dostawca wymaga własnego klucza.

### Aplikacja informuje, że klucz API jest nieprawidłowy

Sprawdź, czy skopiowano cały klucz i czy jest on nadal aktywny na Twoim koncie u dostawcy. W razie potrzeby utwórz nowy klucz.

### Aplikacja informuje o przekroczeniu limitu żądań

Wysłano zbyt wiele żądań lub osiągnięto limit planu. Poczekaj chwilę i spróbuj ponownie albo sprawdź swój plan u dostawcy.

### Nie mogę znaleźć Przetłumacz w menu udostępniania

Najpierw zaznacz tekst, stuknij **Udostępnij** i przewiń w dół do listy czynności. Szukaj pozycji **Przetłumacz** z ikoną Action Translation, ponieważ iOS może pokazywać własną czynność o tej samej nazwie. Aby dodać ją do ulubionych, stuknij **Edytuj czynności…**

### Jak usunąć tłumaczenie?

Przesuń je w lewo w historii i stuknij **Usuń**.
