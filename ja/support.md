# サポート

Action Translation についてお困りですか？お問い合わせいただくか、以下の回答をご覧ください。

## お問い合わせ

[action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) までメールをお送りいただくか、[GitHub で Issue を作成](https://github.com/claustrofob/actiontranslation/issues)してください。Issue は公開されるため、個人情報や API キーは記載しないでください。

## はじめに

1. [Google](https://aistudio.google.com/apikey)、[Anthropic](https://platform.claude.com/settings/keys)、または [OpenAI](https://platform.openai.com/settings/organization/api-keys) で API キーを取得します。
2. アプリで**設定**を開き、プロバイダを選択して、**APIキー**フィールドにキーを貼り付けます。
3. テキストを入力して**翻訳**をタップします。他のアプリから翻訳するには、テキストを選択して**共有**をタップし、**翻訳**をタップします。

## よくある質問

### API キーが必要なのはなぜですか？

Action Translation には独自のサーバやアカウントはありません。本アプリはお客様のキーを使って、選択した AI プロバイダにテキストを直接送信します。利用に伴う料金が発生する場合は、プロバイダとのプランによって決まります。

### API キーがないと表示される

**設定**を開き、使用するプロバイダを選択して API キーを追加してください。プロバイダごとに専用のキーが必要です。

### API キーが無効と表示される

キー全体をコピーしたこと、およびプロバイダのアカウントでキーが有効であることを確認してください。必要に応じて新しいキーを作成してください。

### リクエストの上限を超えたと表示される

リクエストの送信数が多すぎるか、プランの上限に達しています。しばらく待ってからもう一度お試しいただくか、プロバイダのプランをご確認ください。

### 共有メニューに「翻訳」が見つからない

まずテキストを選択し、**共有**をタップして、アクションのリストまでスクロールします。iOS に同じ名前の標準アクションが表示される場合があるため、Action Translation のアイコンが付いた**翻訳**を探してください。よく使う項目に追加するには、**アクションを編集…**をタップします。

### 翻訳を削除するには？

履歴で項目を左にスワイプして、**削除**をタップします。
