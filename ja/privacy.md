# プライバシーポリシー

最終更新日：2026年11月8日

Action Translation は、お客様が選択した AI プロバイダを使ってテキストを翻訳する iPhone および iPad 用アプリです。本ポリシーでは、アプリのご利用時にお客様のデータがどのように扱われるかを説明します。

## 概要

- Action Translation の開発者は、お客様のデータを収集、受信、保存しません。本アプリには、アカウント、サーバ、広告、分析、トラッキングはありません。
- 翻訳を開始すると、テキストはお客様のデバイスから選択した AI プロバイダへ直接送信されます。
- 翻訳履歴、設定、API キーはお客様のデバイスに保存されます。

## AI プロバイダに送信される情報

翻訳を開始するまで、何も送信されません。翻訳を開始すると、本アプリは設定で選択されたプロバイダ（Google、Anthropic、または OpenAI）に、次の情報を直接送信します。

- 翻訳するテキスト
- 翻訳の指示（モデル、翻訳先の言語、選択した場合は翻訳元の言語、アプリの表示言語を含む）
- プロバイダがお客様を識別するための API キー

他のインターネットサービスと同様に、プロバイダは IP アドレスなどの技術的な接続情報も受信します。

プロバイダは、独自の利用規約とプライバシーポリシー、およびお客様との契約に基づいてこれらのデータを取り扱います。条件はプランによって異なる場合があります。たとえば、一部の無料プランでは、送信されたコンテンツをプロバイダが製品の改善に利用することが認められています。機密情報や個人情報を翻訳する前に、プロバイダの規約をご確認ください。

- [Google プライバシーポリシー](https://policies.google.com/privacy)および [Gemini API 利用規約](https://ai.google.dev/gemini-api/terms)
- [Anthropic プライバシーポリシー](https://www.anthropic.com/legal/privacy)
- [OpenAI プライバシーポリシー](https://openai.com/policies/privacy-policy/)

## デバイスに保存される情報

- **翻訳履歴：** 直近 50 件の翻訳（原文、結果、言語、モデル、日付、応答時間を含む）。それより古い翻訳は自動的に削除されます。
- **設定：** プロバイダ、モデル、翻訳先の言語、よく使う言語。
- **API キー：** iOS のキーチェーンに保存されます。

本アプリとその共有機能拡張は、お客様のデバイス上でこれらのデータを共同で使用します。本アプリがこれらのデータをサーバと同期することはありませんが、iOS の設定によってはデバイスのバックアップに含まれる場合があります。

## 他のアプリのコンテンツとデバイスへのアクセス

共有機能拡張が受け取るのは、お客様が共有を選択したテキストまたはリンクのみです。本アプリがクリップボードに書き込むのは、「コピー」をタップしたときのみです。連絡先、写真、位置情報、マイク、カメラへのアクセスは要求しません。

## データの削除

- 翻訳を削除するには、履歴でその項目をスワイプします。
- API キーを削除するには、設定でそのフィールドを空にします。
- アプリを削除すると、履歴と設定が削除されます。アプリの削除後も iOS がキーチェーンの項目を保持する場合があるため、先に API キーを消去してください。
- AI プロバイダが保持するデータの確認や削除については、そのプロバイダにお問い合わせください。

## Apple および本ウェブサイト

App Store からのダウンロードは、Apple が同社のプライバシーポリシーに基づいて取り扱います。iOS の設定でアプリ開発者との分析データの共有を選択した場合、Apple は個人を特定しないクラッシュレポートおよび利用状況レポートを開発者に提供することがあります。

本ウェブサイトは GitHub Pages でホストされており、GitHub が訪問者の IP アドレスを記録する場合があります。本ウェブサイト自体は Cookie や分析ツールを使用していません。

## お子様について

開発者は、お子様を含むいかなる方の個人データも意図的に収集しません。

## 本ポリシーの変更

本ポリシーを変更する場合は、新しい日付とともに新しい版を本ページに掲載します。
