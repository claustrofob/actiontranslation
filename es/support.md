# Soporte

¿Necesitas ayuda con Action Translation? Escríbenos o consulta las respuestas de abajo.

## Contacto

Escribe a [action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) o [abre una incidencia en GitHub](https://github.com/claustrofob/actiontranslation/issues). Las incidencias son públicas, así que no incluyas información personal ni claves de API.

## Primeros pasos

1. Consigue una clave de API de [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys) u [OpenAI](https://platform.openai.com/settings/organization/api-keys).
2. En la app, abre **Ajustes**, elige un proveedor y pega tu clave en el campo **Clave de API**.
3. Escribe el texto y toca **Traducir**. Para traducir desde otra app, selecciona el texto, toca **Compartir** y luego **Traducir**.

## Preguntas frecuentes

### ¿Por qué necesito una clave de API?

Action Translation no tiene servidor ni cuentas propias. Envía tu texto directamente al proveedor de IA que elijas usando tu clave. Los posibles cargos por ese uso dependen de tu plan con el proveedor.

### La app indica que falta la clave de API

Abre **Ajustes**, elige el proveedor que quieras y añade su clave de API. Cada proveedor necesita su propia clave.

### La app indica que la clave de API no es válida

Comprueba que has copiado la clave completa y que sigue activa en tu cuenta del proveedor. Si hace falta, crea una clave nueva.

### La app indica que se ha superado el límite de solicitudes

Has enviado demasiadas solicitudes o has alcanzado el límite de tu plan. Espera un momento y vuelve a intentarlo, o revisa tu plan con el proveedor.

### No encuentro Traducir en el menú Compartir

Primero selecciona el texto, toca **Compartir** y desplázate hasta la lista de acciones. Busca **Traducir** con el icono de Action Translation, porque iOS puede mostrar su propia acción con el mismo nombre. Para añadirla a tus favoritos, toca **Editar acciones…**

### ¿Cómo elimino una traducción?

Deslízala hacia la izquierda en el historial y toca **Eliminar**.
