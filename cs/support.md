# Podpora

Potřebujete pomoc s aplikací Action Translation? Napište nám nebo si přečtěte odpovědi níže.

## Kontakt

Napište na [action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) nebo [založte issue na GitHubu](https://github.com/claustrofob/actiontranslation/issues). Issues jsou veřejné, proto do nich neuvádějte osobní údaje ani API klíče.

## Začínáme

1. Získejte API klíč od společnosti [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys) nebo [OpenAI](https://platform.openai.com/settings/organization/api-keys).
2. V aplikaci otevřete **Nastavení**, vyberte poskytovatele a vložte klíč do pole **API klíč**.
3. Zadejte text a klepněte na **Přeložit**. Chcete-li překládat z jiné aplikace, vyberte text, klepněte na **Sdílet** a potom na **Přeložit**.

## Časté dotazy

### Proč potřebuji API klíč?

Action Translation nemá vlastní server ani účty. Aplikace odesílá text přímo vybranému poskytovateli AI pomocí vašeho klíče. Případné poplatky za toto používání závisí na vašem tarifu u poskytovatele.

### Aplikace hlásí, že chybí API klíč

Otevřete **Nastavení**, vyberte požadovaného poskytovatele a přidejte jeho API klíč. Každý poskytovatel potřebuje vlastní klíč.

### Aplikace hlásí, že API klíč je neplatný

Zkontrolujte, zda jste zkopírovali celý klíč a zda je ve vašem účtu u poskytovatele stále aktivní. V případě potřeby vytvořte nový klíč.

### Aplikace hlásí překročení limitu požadavků

Odeslali jste příliš mnoho požadavků nebo jste dosáhli limitu svého tarifu. Chvíli počkejte a zkuste to znovu, nebo si ověřte tarif u poskytovatele.

### V nabídce sdílení nemohu najít Přeložit

Nejprve vyberte text, klepněte na **Sdílet** a posuňte se dolů na seznam akcí. Hledejte **Přeložit** s ikonou Action Translation, protože iOS může zobrazovat vlastní akci se stejným názvem. Chcete-li ji přidat do oblíbených, klepněte na **Upravit akce…**

### Jak smažu překlad?

V historii přejeďte po překladu doleva a klepněte na **Smazat**.
