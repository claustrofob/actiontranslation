# 지원

Action Translation 사용에 도움이 필요하신가요? 문의하거나 아래 답변을 확인하세요.

## 문의

[action.translation.app@gmail.com](mailto:action.translation.app@gmail.com)으로 이메일을 보내거나 [GitHub에서 이슈를 등록](https://github.com/claustrofob/actiontranslation/issues)하세요. 이슈는 공개되므로 개인정보나 API 키를 포함하지 마세요.

## 시작하기

1. [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys) 또는 [OpenAI](https://platform.openai.com/settings/organization/api-keys)에서 API 키를 받으세요.
2. 앱에서 **설정**을 열고 제공업체를 선택한 다음 **API 키** 입력란에 키를 붙여 넣으세요.
3. 텍스트를 입력하고 **번역**을 탭하세요. 다른 앱에서 번역하려면 텍스트를 선택하고 **공유**를 탭한 다음 **번역**을 탭하세요.

## 자주 묻는 질문

### API 키가 왜 필요한가요?

Action Translation에는 자체 서버나 계정이 없습니다. 앱은 사용자의 키를 사용해 선택한 AI 제공업체로 텍스트를 직접 보냅니다. 사용 요금이 있다면 제공업체와의 요금제에 따라 결정됩니다.

### API 키가 없다고 표시됩니다

**설정**을 열고 원하는 제공업체를 선택한 다음 API 키를 추가하세요. 제공업체마다 별도의 키가 필요합니다.

### API 키가 올바르지 않다고 표시됩니다

키 전체를 복사했는지, 제공업체 계정에서 키가 아직 활성 상태인지 확인하세요. 필요하면 새 키를 만드세요.

### 요청 한도를 초과했다고 표시됩니다

요청을 너무 많이 보냈거나 요금제 한도에 도달했습니다. 잠시 기다린 후 다시 시도하거나 제공업체의 요금제를 확인하세요.

### 공유 메뉴에서 번역을 찾을 수 없습니다

먼저 텍스트를 선택하고 **공유**를 탭한 다음 동작 목록까지 아래로 스크롤하세요. iOS에 같은 이름의 동작이 표시될 수 있으므로 Action Translation 아이콘이 있는 **번역**을 찾으세요. 즐겨찾기에 추가하려면 **동작 편집…**을 탭하세요.

### 번역을 삭제하려면 어떻게 하나요?

기록에서 해당 항목을 왼쪽으로 쓸어 넘기고 **삭제**를 탭하세요.
