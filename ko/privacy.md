# 개인정보 처리방침

최종 업데이트: 2026년 11월 8일

Action Translation은 사용자가 선택한 AI 제공업체를 이용해 텍스트를 번역하는 iPhone 및 iPad용 앱입니다. 이 방침은 앱을 사용할 때 사용자의 데이터가 어떻게 처리되는지 설명합니다.

## 요약

- Action Translation 개발자는 사용자의 데이터를 수집, 수신 또는 저장하지 않습니다. 이 앱에는 계정, 서버, 광고, 분석 또는 추적 기능이 없습니다.
- 번역을 시작하면 텍스트가 사용자의 기기에서 선택한 AI 제공업체로 직접 전송됩니다.
- 번역 기록, 설정 및 API 키는 사용자의 기기에 보관됩니다.

## AI 제공업체로 전송되는 정보

설정에서 API 키를 추가하면 앱이 아래 설명된 데이터를 해당 제공업체로 전송하는 것을 허용하게 됩니다. 허용을 철회하려면 키를 삭제하세요.

번역을 시작하기 전에는 아무것도 전송되지 않습니다. 번역을 시작하면 앱은 설정에서 선택한 제공업체(Google, Anthropic 또는 OpenAI)로 다음 정보를 직접 전송합니다.

- 번역할 텍스트
- 모델, 번역 대상 언어, 선택한 경우 원본 언어, 앱 인터페이스 언어를 포함한 번역 지침
- 제공업체가 사용자를 식별하는 데 사용하는 API 키

다른 인터넷 서비스와 마찬가지로 제공업체는 IP 주소와 같은 기술적 연결 데이터도 수신합니다.

제공업체는 자체 약관과 개인정보 처리방침, 그리고 사용자와의 계약에 따라 이 데이터를 처리합니다. 약관은 요금제에 따라 다를 수 있습니다. 예를 들어 일부 무료 요금제에서는 제공업체가 제출된 콘텐츠를 제품 개선에 사용할 수 있습니다. 기밀 정보나 개인정보를 번역하기 전에 제공업체의 약관을 확인하세요.

- [Google 개인정보처리방침](https://policies.google.com/privacy) 및 [Gemini API 약관](https://ai.google.dev/gemini-api/terms)
- [Anthropic 개인정보 처리방침](https://www.anthropic.com/legal/privacy)
- [OpenAI 개인정보 처리방침](https://openai.com/policies/privacy-policy/)

## 기기에 보관되는 정보

- **번역 기록:** 원문, 결과, 언어, 모델, 날짜, 응답 시간을 포함한 최근 50개의 번역. 이보다 오래된 번역은 자동으로 삭제됩니다.
- **설정:** 제공업체, 모델, 번역 대상 언어 및 가장 자주 사용하는 언어.
- **API 키:** iOS 키체인에 저장됩니다.

앱과 공유 확장 프로그램은 사용자의 기기에서 이 데이터를 함께 사용합니다. 앱은 이 데이터를 어떤 서버와도 동기화하지 않지만, iOS 설정에 따라 기기 백업에 포함될 수 있습니다.

## 다른 앱의 콘텐츠 및 기기 접근 권한

공유 확장 프로그램은 사용자가 공유하기로 선택한 텍스트나 링크만 받습니다. 앱은 사용자가 복사를 탭할 때만 클립보드에 기록합니다. 연락처, 사진, 위치, 마이크 또는 카메라에 대한 접근 권한을 요청하지 않습니다.

## 데이터 삭제

- 번역을 삭제하려면 기록에서 해당 항목을 쓸어 넘기세요.
- API 키를 제거하려면 설정에서 해당 입력란을 비우세요.
- 앱을 삭제하면 기록과 설정이 제거됩니다. 앱을 삭제한 후에도 iOS에 키체인 항목이 남아 있을 수 있으므로 먼저 API 키를 지우세요.
- AI 제공업체가 보관하는 데이터를 열람하거나 삭제하려면 해당 제공업체에 문의하세요.

## Apple 및 이 웹사이트

App Store 다운로드는 Apple이 자체 개인정보 처리방침에 따라 처리합니다. iOS 설정에서 앱 개발자와 분석 정보를 공유하도록 선택한 경우 Apple은 사용자를 식별하지 않는 충돌 및 사용 보고서를 개발자에게 제공할 수 있습니다.

이 웹사이트는 GitHub Pages에서 호스팅되며, GitHub는 방문자의 IP 주소를 기록할 수 있습니다. 웹사이트 자체는 쿠키나 분석 도구를 사용하지 않습니다.

## 아동

개발자는 아동을 포함한 누구의 개인정보도 고의로 수집하지 않습니다.

## 방침 변경

이 방침이 변경되면 새로운 날짜와 함께 새 버전을 이 페이지에 게시합니다.
