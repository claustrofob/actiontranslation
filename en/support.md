# Support

Need help with Action Translation? Contact us or check the answers below.

## Contact

Email [action.translation.app@gmail.com](mailto:action.translation.app@gmail.com) or [open an issue on GitHub](https://github.com/claustrofob/actiontranslation/issues). Issues are public, so do not include personal information or API keys.

## Getting started

1. Get an API key from [Google](https://aistudio.google.com/apikey), [Anthropic](https://platform.claude.com/settings/keys), or [OpenAI](https://platform.openai.com/settings/organization/api-keys).
2. In the app, open **Settings**, choose a provider, and paste your key into the **API Key** field.
3. Enter text and tap **Translate**. To translate from another app, select the text, tap **Share**, then tap **Translate**.

## Common questions

### Why do I need an API key?

Action Translation has no server or account of its own. It sends your text directly to the AI provider you choose, using your key. Any charges for that use come from your plan with the provider.

### The app says the API key is missing

Open **Settings**, choose the provider you want, and add its API key. Each provider needs its own key.

### The app says the API key is invalid

Check that you copied the whole key and that it is still active in your provider account. If needed, create a new key.

### The app says the rate limit is exceeded

You have sent too many requests or reached your plan's limit. Wait a moment and try again, or check your plan with the provider.

### I can't find Translate in the Share menu

Select the text first, tap **Share**, and scroll down to the list of actions. Look for **Translate** with the Action Translation icon, because iOS may show its own action with the same name. To add it to your favorites, tap **Edit Actions…**

### How do I delete a translation?

Swipe it to the left in the history and tap **Delete**.
