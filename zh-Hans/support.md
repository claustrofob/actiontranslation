# 支持

使用 Action Translation 时需要帮助？请联系我们或查看下方解答。

## 联系我们

请发送电子邮件至 [action.translation.app@gmail.com](mailto:action.translation.app@gmail.com)，或[在 GitHub 上提交 issue](https://github.com/claustrofob/actiontranslation/issues)。Issue 是公开的，请勿在其中填写个人信息或 API 密钥。

## 快速上手

1. 从 [Google](https://aistudio.google.com/apikey)、[Anthropic](https://platform.claude.com/settings/keys) 或 [OpenAI](https://platform.openai.com/settings/organization/api-keys) 获取 API 密钥。
2. 在 App 中打开**设置**，选择提供商，然后将密钥粘贴到 **API 密钥**字段中。
3. 输入文本并轻点**翻译**。要从其他 App 翻译，请选择文本，轻点**共享**，然后轻点**翻译**。

## 常见问题

### 为什么需要 API 密钥？

Action Translation 没有自己的服务器或账户。App 会使用你的密钥，将文本直接发送给你选择的 AI 提供商。相关使用费用（如有）取决于你在该提供商处的方案。

### App 提示缺少 API 密钥

打开**设置**，选择所需的提供商并添加其 API 密钥。每个提供商都需要各自的密钥。

### App 提示 API 密钥无效

请检查是否完整复制了密钥，以及该密钥在你的提供商账户中是否仍然有效。如有需要，请创建新的密钥。

### App 提示超出请求限制

你发送的请求过多，或已达到方案的限额。请稍等片刻后重试，或查看你在该提供商处的方案。

### 在共享菜单中找不到“翻译”

请先选择文本，轻点**共享**，然后向下滚动到操作列表。请查找带有 Action Translation 图标的**翻译**，因为 iOS 可能会显示同名的系统操作。要将其添加到个人收藏，请轻点**编辑操作…**

### 如何删除翻译？

在历史记录中向左轻扫该条目，然后轻点**删除**。
