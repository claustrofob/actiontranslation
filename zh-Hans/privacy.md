# 隐私政策

最后更新：2026 年 11 月 8 日

Action Translation 是一款适用于 iPhone 和 iPad 的 App，它使用你选择的 AI 服务商来翻译文本。本政策说明你在使用该 App 时，你的数据会如何处理。

## 概要

- Action Translation 的开发者不会收集、接收或存储你的数据。该 App 没有账户、服务器、广告、分析或跟踪功能。
- 当你开始翻译时，文本会从你的设备直接发送给你所选的 AI 服务商。
- 你的翻译历史、设置和 API 密钥都保存在你的设备上。

## 发送给 AI 服务商的内容

在你开始翻译之前，不会发送任何内容。开始翻译后，App 会将以下内容直接发送给你在设置中选择的服务商（Google、Anthropic 或 OpenAI）：

- 你要翻译的文本；
- 翻译指令，包括模型、目标语言、源语言（如果你已选择）以及 App 的界面语言；
- 你的 API 密钥，服务商用它来识别你的身份。

与任何互联网服务一样，服务商还会收到技术连接数据，例如你的 IP 地址。

服务商会根据其自身的条款、隐私政策以及你与其达成的协议处理这些数据。不同方案的条款可能不同：例如，部分免费方案允许服务商使用提交的内容改进其产品。在翻译机密信息或个人信息之前，请查看服务商的条款。

- [Google 隐私权政策](https://policies.google.com/privacy)和 [Gemini API 条款](https://ai.google.dev/gemini-api/terms)
- [Anthropic 隐私政策](https://www.anthropic.com/legal/privacy)
- [OpenAI 隐私政策](https://openai.com/policies/privacy-policy/)

## 保留在你设备上的内容

- **翻译历史：**最近 50 条翻译，包括原文、结果、语言、模型、日期和响应时间。更早的翻译会自动删除。
- **设置：**你的服务商、模型、目标语言以及最常用的语言。
- **API 密钥：**存储在 iOS 钥匙串中。

App 及其共享扩展会在你的设备上共同使用这些数据。App 不会将它们同步到任何服务器，但根据你的 iOS 设置，它们可能会包含在设备备份中。

## 来自其他 App 的内容和设备访问权限

共享扩展只会接收你选择共享给它的文本或链接。只有当你轻点“拷贝”时，App 才会写入剪贴板。App 不会请求访问你的通讯录、照片、位置、麦克风或相机。

## 删除你的数据

- 要删除某条翻译，请在历史记录中轻扫该条目。
- 要移除 API 密钥，请在设置中清空其字段。
- 删除 App 会移除你的历史记录和设置。App 删除后，iOS 可能仍会保留钥匙串项目，因此请先清除 API 密钥。
- 如需访问或删除 AI 服务商保存的数据，请联系相应的服务商。

## Apple 和本网站

App Store 下载由 Apple 根据其隐私政策处理。如果你在 iOS 设置中选择与 App 开发者共享分析数据，Apple 可能会向开发者提供不会识别你身份的崩溃和使用情况报告。

本网站托管在 GitHub Pages 上，GitHub 可能会记录访问者的 IP 地址。本网站本身不使用 Cookie 或分析工具。

## 儿童

开发者不会故意收集任何人的个人数据，包括儿童的个人数据。

## 本政策的变更

如果本政策发生变更，新版本将发布在此页面上，并注明新的日期。

## 联系方式

如有疑问，请[在 GitHub 上提交 issue](https://github.com/claustrofob/actiontranslation/issues)。Issue 是公开的，请勿在其中填写个人信息或 API 密钥。如有隐私相关请求，请发送电子邮件至 [action.translation.app@gmail.com](mailto:action.translation.app@gmail.com)。
